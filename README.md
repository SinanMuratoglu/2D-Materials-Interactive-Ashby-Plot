# 2D Materials Interactive Ashby Plot

Interactive Ashby-style property map of two-dimensional materials from
[2DMatPedia](http://www.2dmatpedia.org/). 

**Live site:** https://sinanmuratoglu.github.io/2D-Materials-Interactive-Ashby-Plot/

## Features

- 17 selectable axes, band gap, exfoliation energy, energy above hull,
  areal mass density, layer thickness, magnetization, band edges, lattice constants...
- 9 colour-coded families
- Family envelopes: a kernel-density contour enclosing a chosen share (50–95%) of each
  family
- Eport visible data as CSV or plot as PNG
- The view is stored in the URL, link reproduces same plot

## Notes on data

- Values are DFT (PBE) from 2DMatPedia. PBE underestimates band gaps.
- Top-down vs. bottom-up:
  - Top-down materials are identified by screening bulk crystals in Materials Project for
    structures composed of layers held together by van der Waals interactions. Authors then
    isolated a single layer and relax using DFT. As such, exfoliation energy is defined.
  - Bottom-up 2D materials are hypothetical, generated by elemental substitution into top-down
    structures as templates. Thus usually no exfoliation energy reported. 
- Derived properties come from the relaxed structures
- Layer thickness is the atomic span normal to the layer (e.g. 0 Å for graphene)
- Areal densities use in-plane cell area
- Exfoliation energy per area = exfoliation energy per atom / area per atom.
- Families are assigned by composition rules in `scripts/build_dataset.py`. "TMD (MX₂)"
  means binary transition-metal + S/Se/Te in a 1:2 ratio. Other chalcogenides, such as Ta₂Te₃,
  fall under "Other chalcogenide".
- 2DMatPedia contains no mechanical properties (modulus, strength).
